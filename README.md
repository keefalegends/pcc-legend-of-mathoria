Legend Of Marthortia
Banyak siswa merasa kesulitan dan bosan dalam belajar matematika karena metode pembelajaran yang monoton. Kurangnya media interaktif membuat siswa kurang tertarik untuk belajar. Oleh karena itu, dibuat game edukasi berbasis RPG agar proses belajar matematika menjadi lebih menyenangkan dan interaktif.
